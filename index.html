Method and data notes

Harmonisation

  • Values are GWP-total (fossil + biogenic + LULUC) in kgCO₂e over a 50-year reference study period; “per year” divides by 50.
  • Embodied = A1–A3, A4, A5, B4–B5 and C1–C4, the modules all four datasets share. Whole life adds B2–B3, B6 and B7 where reported. Module D is always shown separately.
  • Intervention. Italy includes 21 renovations (12 minor, 9 major). They are shown only when the intervention filter includes renovation, and are benchmarked separately from new construction. Austria and Luxembourg do not state the intervention type and are treated as new construction.
  • Building types are mapped to harmonised types; the Italian codes HOS and XTR are not defined in the file and stay as their own types. National typologies are kept in the building table (Austrian “Apartment block” and “Multi-family house” both map to Multi-family / apartments).

Assumptions to confirm

  • Luxembourg reference area. The LU results are already per m², but the file does not state which area. They are treated as per m² GFA (total incl. below ground) and converted with the A. Metadata areas.
  • Italy, floor area. Italy reports GFA and heated floor area (HFA) but no UFA. In per-UFA views HFA is used instead.
  • Italy, typologies HOS and XTR. Residential (HOS, grouped with MFH in the source) and non-residential (XTR) codes without a definition in the file.
  • Italy, element tiers. The tier names are not given in the file. Tier values include proxies for missing values, outlier replacements and cross-typology proxies, flagged by cell colour in the source; tier sums are 0.92–1.69× the life-cycle embodied totals (median 1.07).
  • Austria, operational energy. The column header reads “GWP total - B5” but its description row says B6; it is treated as B6. Austrian B4–B5 contains B4 only.
  • Luxembourg “House” includes some larger multi-unit residences (e.g. MI_Con_1, 35 occupants); it is mapped to Single-family house as labelled.

Data quality flags

  • Croatia: the 50 cases are design variants of 16 base buildings (pairs share identical floor areas), so percentiles describe variants rather than an independent stock. The per-GFA B3 column in the source holds a running index; values here are recomputed from the absolute totals (which match the source totals within 2 kgCO₂e).
  • Austria reports no GFA, so it drops out when the area is set to GFA.
  • Luxembourg reports no operational modules (B6/B7), so it drops out of the whole-life view; its element scope covers shell, core and services plus external works.
  • Italy: B2 and B3 are GWP-fossil only; B6 = 0 for IT-EDU_01 and IT-XTR_07 is treated as not reported; IT-OFF_07 and IT-OFF_08 report an identical B6 value, as do the four variants IT-MFH_17/20/21/25.
  • System boundaries and element scope of the AT and HR models are not documented in the files, so cross-country gaps may reflect scope as well as performance.
