# INDICATE WLC Dashboard

> **Work in progress.** These results are preliminary and haven't been verified yet. Data harmonisation and assumptions are still being checked with the INDICATE LIFE national teams. Please don't cite or reuse the figures.

A web dashboard and harmonised database of the whole life carbon (WLC) of buildings in the INDICATE LIFE national datasets.

| Deliverable | Country | Buildings | Lead organisation |
|---|---|---|---|
| D7.3 AT national WLC dataset | Austria | 67 | TU Graz |
| D7.12 HR national WLC dataset | Croatia | 50 | University of Zagreb, Faculty of Civil Engineering |
| D7.21 IT national WLC dataset | Italy | 50 (29 new construction, 21 renovations) | POLIMI, with POLITO, UNIBG and Harpaceas |
| D7.30 LU national WLC dataset | Luxembourg | 52 | Energie et Environnement S.A. (on behalf of the OAI) |

The database follows the **INDICATE Building Whole Life Cycle Emissions Reporting Template v1.1**. Version 1.1 is a draft with corrections and extensions of v1.0: Röck, M. (2026). *INDICATE – Building Whole Life Cycle Emissions Reporting Template.* Zenodo. <https://doi.org/10.5281/zenodo.21169904>. It uses:

- the template's attribute codes (e.g. `bldg_area_gfa`, `lca_rsp`);
- its 16 life-cycle modules (A1–A3 … D2, including B5);
- its 9 building types (SFH, MFH, ABL, OFF, TRA, EDU, HEA, HOR, OTH);
- the element tiers of the EU Delegated Regulation Table 4, as used in the template's new emissions-by-element tab.

The dashboard shows:

- the distribution of WLC per m² by building type;
- contributions across life-cycle modules;
- contributions by building element (EU Table 4 tiers; Italy and Luxembourg);
- material groups (Luxembourg);
- statistical benchmark classes (Best practice ≤ P25, Reference ≤ P50, Limit ≤ P75, Above limit; terms of D3.1/D3.2);
- the building records;
- reporting completeness against the template.

INDICATE LIFE, National Building LCA Data Accelerator EU LIFE, is co-funded by the European Union's LIFE programme under grant agreement 101167585. Website: <https://www.indicatedata.com/>

## Repository contents

```
index.html                          the dashboard (static HTML, CSS and JavaScript, no build step)
assets/js/data.js                   dashboard data, generated by the pipeline
assets/css/, assets/fonts/          self-hosted web fonts incl. Montserrat (SIL Open Font License 1.1)
assets/img/                         INDICATE LIFE logo and EU emblem ("Co-funded by the European Union")
data/INDICATE_WLC_database.xlsx     harmonised database (template v1.1 vocabulary): projects, results, statistics,
                                    template-module results, elements, codebook with completeness, mappings,
                                    issues log with questions, QA checks, processing steps
data/csv/                           the main tables as CSV
data/data-requests/                 one pre-filled template v1.1 per country, to send to the national teams
template/                           INDICATE reporting template v1.1 (draft) used as the schema
pipeline/                           Python harmonisation pipeline; see pipeline/README.md
robots.txt                          keeps search engines away while this is a preview
.nojekyll                           tells GitHub Pages to serve the files as they are
```

**Design.** The page follows the INDICATE LIFE Brand Guidelines (D6.2): logo top right, Montserrat, navy text, and chart colours taken from the D3.2 synthesis report (brand colours and their tints: Austria green, Croatia navy, Italy coral, Luxembourg violet; benchmark thresholds P25 green, P50 violet, P75 coral). Adjacent colours were checked for colour-vision deficiency. The footer carries the EU emblem and the LIFE funding statement.

The page runs entirely in the browser. It has no server, database, cookies, analytics or browser storage, and loads nothing from third-party servers.

## Publish with GitHub Pages

1. Create a repository, e.g. `indicate-wlc-dashboard`. Public repositories can use Pages on every GitHub plan.
2. Upload the **contents** of this folder to the repository root: *Add file → Upload files*, including the `assets`, `data`, `pipeline` and `template` folders.
3. Go to *Settings → Pages*, choose **Deploy from a branch**, set branch **`main` / `(root)`**, and save.
4. After a minute or two the site is live at `https://<account>.github.io/indicate-wlc-dashboard/`.

### Custom domain later (e.g. `dashboard.indicatedata.com`)

1. In the DNS settings of `indicatedata.com`, add a **CNAME** record with host `dashboard` and value `<account>.github.io`.
2. In the repository, go to *Settings → Pages → Custom domain*, enter the domain, and tick **Enforce HTTPS** once it is available.

## Updating the data

The source workbooks aren't stored in this repository; put them in a local `source/` folder (ignored by git). Then run:

```bash
pip install -r pipeline/requirements.txt
python pipeline/run_all.py source
```

This rewrites `data/`, the data requests and `assets/js/data.js`. It prints the processing log and the reconciliation checks, and stops if a check fails. When the national teams return their completed templates, their values can be added in the extractors (`pipeline/extract_<country>.py`).
